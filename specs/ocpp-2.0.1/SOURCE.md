# OCPP 2.0.1 JSON schemas

These are the OCPP 2.0.1 FINAL JSON schemas (draft-06), 64 messages × Request/Response = 128
files, published by the Open Charge Alliance.

- **Origin:** Open Charge Alliance, OCPP 2.0.1 package, part 3 (JSON schemas).
  The official download at https://openchargealliance.org/download-ocpp/ needs an OCA account.
- **Copied from:** https://github.com/mobilityhouse/ocpp at commit
  `0adf9458b15b7acc605d3a13355f76d14f22fdc9`, path `ocpp/v201/schemas/`. That library ships
  the OCA schema files, and every file here has `"comment": "OCPP 2.0.1 FINAL"`.
- **Downloaded:** 2026-09-28.

  Attribution-NoDerivatives 4.0 (CC BY-ND 4.0). Keep these files unmodified.
